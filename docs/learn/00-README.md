# Учебный курс: с нуля в TS до проекта Dinero

Этот курс — ответ на один конкретный запрос: «я вообще не шарю TS и что
за что отвечает — проведи меня с полного нуля до этого проекта». Он не
заменяет [`SKELETON.md`](../../SKELETON.md) (терсную справку по каждому
модулю и сигнатуре) — он даёт знания, после которых `SKELETON.md`
становится читаемым, а код проекта — навигируемым.

## Что я предполагаю про тебя

- Ты умеешь работать в терминале, знаешь git, редактировал конфиги на
  Lua (Hyprland) или Scheme (Thunar) — то есть общую логику
  программ (переменные, функции, условия, циклы) ты уже понимаешь
  интуитивно.
- Ты **не** писал на TypeScript/JavaScript, не трогал React, не видел
  Tauri и, возможно, не писал SQL руками.

Поэтому здесь нет глав «что такое переменная» — зато подробно разобран
именно синтаксис и идиомы TS/JS, модель компонентов React, граница
фронтенд/бэкенд в Tauri и реляционные таблицы SQL.

## Как использовать учебные фрагменты кода

В каждой главе код двух видов:
- **Учебный пример** — придуманный, нигде в проекте не существует,
  просто чтобы показать синтаксис.
- **Реальный пример** — помечен путём к файлу (например
  `src/db/statements.ts:20`), скопирован из настоящего кода проекта.

Когда дойдёшь до главы 10 и `SKELETON.md` — там уже только реальный код
и сигнатуры, учебных примеров больше не будет.
